# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、失效待重算、冲突说明、冻结批次与差异趋势
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：规则版本与有效基线核对、失效重算、并发冲突留痕和审批入口
- 发布冻结批次：把已批准运行的结论、规则版本和历史基线固化为原证据
- 历史基线：版本、批准人、原因、关联运行、规则版本和启用状态
- 忽略规则：规则集版本化管理；增删改后待审批运行失效待重算
- 结果导出：导出包含审批结果、规则/基线依据和冲突说明的 CSV

## 冻结期审批规则

- 评审人与发布负责人可在两个窗口同时提交同一运行（详情页可切换窗口身份）；以先落地且核对通过者为准。
- 提交前核对忽略规则版本与当前有效基线：规则落后则运行失效、需重新计算；基线落后的一方不能盖掉新基线，只在运行上保留冲突说明。
- 规则变化仅使待审批/失效运行失效重算；已批准结论与已锁定发布批次继续使用原证据。
- 写入前备份最近完整记录、写入后回读校验；批准缺历史基线、同页面设备出现两条有效基线等不一致状态一律拒绝并恢复。
- 列表、详情、导出和概览共用同一个审批结果与依据（`ApprovalEvidence` 组件与 `utils/approval.ts`）。

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v2` 对应的本地存储键。
