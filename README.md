# 视觉回归基线审批与差异定位平台

基于 Vue 3 的本地可运行前端工程，用于管理截图回归运行、差异定位、忽略规则和基线审批。数据由 Axios 模拟适配器提供，并持久化到浏览器 `localStorage`。

## 技术栈

- Vue 3 + TypeScript + Vite
- Arco Design Vue
- Pinia
- Vue Router
- TanStack Query for Vue
- Axios

## 启动

```bash
npm install
npm run dev
```

默认开发地址为 `http://localhost:18471`。

## 构建

```bash
npm run build
npm run preview
```

## 工作区

- 运行概览：发布阻断项、差异趋势和最近运行
- 回归运行：按项目、页面、设备、主题、构建和状态筛选，合并重复运行
- 差异定位：基线/当前图并排、区域缩放、严重级筛选、区域忽略和审批
- 审批队列：批量合并、风险排序和审批入口
- 历史基线：版本、批准人、原因、关联运行和启用状态
- 忽略规则：动态区域选择器、作用范围、最大色差和启用控制
- 结果导出：导出包含运行、差异和审批证据的 CSV

浏览器首次打开时会自动写入示例数据。审批或规则调整会写入 `visual-regression-platform-v1` 对应的本地存储键。

## 一致性设计

- **并发审批**：审批请求携带提交人看到的忽略规则版本与当前有效基线，服务端写入前重新核对。落后的一方不会盖掉新基线，只在运行上留下冲突说明（评审人与发布负责人两个窗口同时提交同一运行时生效）。
- **规则版本**：忽略规则每次增删改都会递增全局规则版本，未锁定批次的待审批运行随之失效重算；已锁定的发布批次继续使用原证据，审批按锁定时的规则版本核对。
- **事务写入**：每次写入先把当前完整记录存入备份键再写主记录，任一步失败都会回滚到最近完整记录；主记录损坏时读取方会自动从备份恢复。
- **状态约束**：「运行已批准却没有历史基线」「同一页面 + 设备 + 主题存在两条有效基线」的数据一律拒绝落库，历史遗留数据在读取时自动修复。
- **统一依据**：回归运行列表、差异定位详情、结果导出 CSV 和运行概览展示同一份审批结论与依据（批准人、依据基线、规则版本、冲突说明）。
